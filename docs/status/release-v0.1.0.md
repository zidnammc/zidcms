## ZidCMS — v0.1.0 release checklist (early stage, 2026-11-21)

v0.1.0 is an early-stage release, published on GitHub as a pre-release. Private values (URLs of Apps Script deployments, spreadsheet/Drive/GCP/Vercel IDs, secrets, e-mail addresses) are kept in the owner's gitignored files and are not recorded here. Result files under `tests/integration/results/`, `tests/e2e/results/` and `test-results/` are gitignored and stay on the owner's machine.
