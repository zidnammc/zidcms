# 0009: Implementation adjustments relative to the original design and the UI prototype

- **Status:** accepted (2026-11-21).

| Area                      | Original design / prototype                                                  | Implemented                                                                                                                                      | Reason                                                                                                                 |
| ------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| UI language               | not specified                                                                | Bahasa Indonesia, following the prototype (owner decision 2026-11-21)                                                                            | owner                                                                                                                  |
| Prototype                 | Vite SPA with simulated backend, simulator bar, fake latency/failure toggles | Ported visual language (Tailwind classes, layout, badges, copy) into Next.js App Router screens backed by the real API; simulator removed        | production code                                                                                                        |
| Styling                   | Tailwind 3 (prototype)                                                       | Tailwind 4 CSS-first config; shared `.zid-prose` stylesheet exported from `@zidcms/core/prose.css` so admin preview and public site match        | current major, single source of prose styles                                                                           |
| Snapshot `site`           | original snapshot schema                                                     | adds `allowExternalImages`                                                                                                                       | renderer needs it at build time                                                                                        |
| Media paths               | prototype: 16-char sha prefix                                                | full sha256                                                                                                                                      | collision-free (ADR-0004)                                                                                              |
| RPC catalog               | original RPC catalog                                                         | adds `system.summary` (one RPC per admin screen for counts, active job, live snapshot), `publish.claimStep`, `snapshots.setStatus`, `audit.list` | design rule "one RPC per screen load", ADR-0008                                                                        |
| HTTP API                  | original HTTP API                                                            | `/api/categories`, `/api/tags` share one handler factory; `GET /api/media` lists media; status filter `trash` on list endpoints                  | trash view                                                                                                             |
| Preview route             | `/preview/posts/[id]`                                                        | `/preview/[kind]/[id]` (posts and pages)                                                                                                         | pages share the editor                                                                                                 |
| Pending-changes indicator | original design                                                              | computed from the live snapshot (read from the snapshot store by commit SHA, cached per SHA) + settings/taxonomy `updated_at`                    | no separate live index file                                                                                            |
| Snapshot privacy          | "no value matches an e-mail regex outside `authorName`"                      | build fails when any value outside `authorName` contains an actor e-mail (`created_by`/`updated_by`)                                             | a generic e-mail regex would block legitimate contact addresses in posts; the actual risk is leaking the admin address |
| Taxonomy deletion         | category must exist                                                          | deleted categories/tags are dropped from posts with a publish warning instead of failing the publish                                             | avoids un-publishable content after a taxonomy cleanup                                                                 |
